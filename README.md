# Ahmed Hussein Personal Website

Bilingual Arabic and English personal website for Ahmed Hussein Abdallah Sayed, electrical engineer in Mut, New Valley, Egypt.

## Files
- index.html: complete static website.
- images/ahmed-profile.jpeg: profile photo.
- projects/: project gallery photos.

## Run locally
Open index.html in a browser. No build step or dependencies are required.

## Publish with GitHub Pages
Upload these files to the root of a GitHub repository, then enable GitHub Pages in Settings → Pages. Choose the main branch and root folder.
